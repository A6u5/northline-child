# Plugin baseline

Start every site with this list. Add nothing else without a written reason.

| Plugin | Why |
|---|---|
| WooCommerce | Store core |
| WooCommerce PayPal Payments | Official gateway (only when the client uses PayPal) |
| Yoast SEO | Client-editable meta descriptions, sitemap |
| UpdraftPlus (to be installed per site) | Scheduled backups before any deploy |

Not in the baseline: page builders, multi-purpose "all in one" plugins, extra cache or
security plugins (decided per host).
